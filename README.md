# PesoWise

PesoWise is an Android personal finance application that helps users manage their money, track expenses, create budgets, and monitor their spending.

## Features

- **Transaction History** – Record income and expenses, automatically sort transactions by date, and search using a date range.
- **Budget Monitoring** – Create monthly budgets and track available money.
- **Expense Breakdown** – View planned expenses, actual spending, and remaining amounts.
- **Automatic Calculations** – Check whether you have enough money or have exceeded your budget.
- **Budget Progress Bar** – Green represents remaining money, while red represents money spent.
- **Financial Reports** – Review financial activities and spending.
- **Calendar and Reminders** – Set reminders for upcoming bills and payments.

## Technologies Used

- Kotlin
- Android Studio
- XML
- Gradle
- SharedPreferences

## How to Run

1. Download or clone the repository.
2. Open the project in Android Studio.
3. Wait for Gradle to sync.
4. Select an Android emulator or physical device.
5. Click **Run** to launch PesoWise.

## Purpose

PesoWise aims to make personal budgeting easier by helping users organize expenses, monitor their finances, and make better financial decisions.
